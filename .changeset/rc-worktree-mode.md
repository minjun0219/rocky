rc 대상에 워크트리 모드(`rc.worktree`)를 더한다. 목록에 적은 폴더의 서버를 `claude rc --spawn worktree` 로 띄워, 앱이나 claude.ai 프로젝트가 그 폴더에 여는 세션마다 제 git 워크트리를 받는다. 같은 폴더에 세션이 여럿 떠도 작업 트리를 나눠 쓰지 않는다. 워크트리 대상의 재시작 · 야간 재시작은 열린 세션을 이어받지 않고 새로 띄운다(이어받기는 세션 하나만 받는 모드라 워크트리와 같이 쓸 수 없다). 목록은 기본으로 비어 있다 — 세션 하나만 나누려면 이 설정 없이 그 세션에 워크트리를 청한다(Claude Code `EnterWorktree`). 재시작 · 야간이 기다리는 "대화 중" 판정은 목록과 상관없이 그 폴더 워크트리의 대화 기록까지 본다(rocky 핸드오프의 `todo-<번호>` 는 뺀다). `rocky rc` 는 워크트리 대상을 표시하고, 설정과 떠 있는 서버의 모드가 다르면 "다시 띄우면 켜짐 · 꺼짐" 으로 알린다(그 사이 재시작 · 야간도 워크트리 모드로 떠 있는 서버의 세션은 이어받지 않는다). `rocky rc targets` 는 대상이 아닌 워크트리 이름(오타)을 ⚠ 로 알리고, `rocky rc targets rm` 은 워크트리 목록에서도 그 폴더를 지운다. `rocky rc reload` 가 켜고 끈 대상과 다시 띄우는 법을 알린다. 웹 원격 제어 탭의 재시작 확인 줄도 워크트리 대상이면 "서버만 새로 뜬다" 고 말한다.
