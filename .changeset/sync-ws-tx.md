웹 소켓(`/api/ws`)에 트랜잭션 프레임을 더했다. `{t:"tx", id, ops:[…]}` 로 할 일·댓글·섹션·노트·보드 제목을 고치면 결과 행(`rows`)이 먼저 오고 `ack` 가 뒤따른다. 할 일·노트·댓글 만들기는 클라이언트가 정한 id 를 써서 다시 보내도 두 번 만들어지지 않는다. 사람의 쓰기 전용이라 에이전트 actor 는 거절하고, 세션 띄우기·이슈·핸드오프처럼 실행으로 이어지는 쓰기는 이 프레임으로 할 수 없다. 아직 웹 화면은 쓰지 않는다(다음 조각).
