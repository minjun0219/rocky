기간: `$ARGUMENTS` (비어 있으면 `30d`)

rocky 는 자기 표면(REST · MCP 도구 · CLI · 훅 · 웹 UI 이벤트)이 얼마나 쓰이는지를 상시 기록한다
(`docs/board.md` "사용 로그"). 이 커맨드는 그 수치를 읽고 **개선 후보를 제안**하는 자리다 —
무엇을 끄거나 바꿀지는 사용자가 정한다. 출력은 한국어, 식별자·명령은 영어 그대로.

## 절차

### 1. 수치를 받는다

```bash
rocky usage --since 30d --json   # `$ARGUMENTS` 가 있으면 30d 자리에 그 값을 넣는다 (예: 90d · 2w)
```

- 셸 기본값 문법(`${ARGUMENTS:-30d}`)은 쓰지 않는다 — Claude Code 는 `$ARGUMENTS` 만 치환하고
  그 꼴은 셸의 무관한 환경변수로 풀려 늘 30d 가 된다.

- `rocky` 가 없으면 `~/.local/share/rocky/current/rocky`. 로그가 꺼져 있거나(`usage.enabled:
  false`) 비어 있으면 그 사실만 알리고 끝낸다 — 없는 수치로 제안하지 않는다.
- 기간이 짧으면(7일 미만) "안 쓴 표면" 은 근거가 약하다고 먼저 말한다. 월 1회 쓰는 표면은
  30일에도 0으로 보일 수 있다 — 90일을 함께 보라고 권한다.

### 2. 세 묶음으로 읽는다

| 묶음 | 근거 | 제안 형태 |
| --- | --- | --- |
| **뺄 후보** | `unused` 에 있고, 90일에도 0 이며, 대체 경로가 있는 표면 | "X 는 N일간 0건 — Y 로 대신 된다. 빼도 되나?" |
| **손볼 후보** | `errors` 비율이 높거나(>10%) p95 가 눈에 띄게 큰 표면(>2s) | "X 가 N번 중 M번 실패 / p95 Ns — 원인 후보: …" |
| **더 쓸 후보** | 많이 쓰는 경로 옆의 안 쓰는 지름길(예: 웹 `todo-open` 은 많은데 `now-row` 는 0) | "A 를 자주 쓰는데 B 를 안 쓴다 — B 가 안 보이거나 안 필요한 것" |

- 표면 이름은 `rocky_core::usage::KNOWN_SURFACES` 의 것이다. 거기 없는 새 이름이 로그에
  보이면 "전수 목록에 빠졌다" 도 한 줄로 알린다.
- 클라이언트 비율(web/tui/cli/mcp)과 시각 분포는 맥락으로만 — "TUI 를 안 쓴다" 는 뺄 근거가
  아니라 "폰에서 본다" 의 근거일 수 있다.

### 3. 제안은 짧게, 결정은 사용자에게

```
사용 로그 30일 · 1,240건 (web 61% · mcp 30% · cli 9%)

뺄 후보
  rocky tailscale — 90일 0건, 노출은 rocky.json expose 로 이미 됨
손볼 후보
  POST /api/todos/:ref/spawn — 12건 중 4건 실패(409 겹침) · p95 31s
더 쓸 후보
  web:now-row 0건인데 web:todo-open 210건 — "지금" 표를 안 누른다
```

- 묶음당 최대 3개. 근거 없는 항목은 적지 않는다.
- 사용자가 고르면: 뺄 것 → `AGENTS.md` *Scope → Out* 갱신 + 코드 제거 PR(본문에 수치 인용),
  손볼 것 → 보드 항목(`todo_write`, 수치를 description 에), 더 쓸 것 → UX 항목.
- **자동으로 끄거나 지우지 않는다.** 로그는 근거이지 판결이 아니다.

## 실패 / 예외

| 상황 | 처리 |
| --- | --- |
| `rocky usage` 가 "꺼져 있다" | 켜는 법(`usage.enabled` / `ROCKY_USAGE`) 안내 후 끝 |
| 기록 0건 | 데몬·CLI 가 이 버전으로 돈 뒤부터 쌓인다고 알리고 끝 |
| 기간 파싱 실패 | `30d` · `12h` · `2w` 꼴 안내 |
